# Тест-кейсы

Источник сценариев — Приложение А ТЗ (демонстрационный сценарий, шаги 1–12).
Тест-кейсы нужны для отчёта о проверке на физическом устройстве (сдача хакатона) и как вход для skills
`android-component-test-automator` / `android-e2e-test-automator`.

Автотест, закрывающий кейс, указывает ID в KDoc над тестом: `/** TC-01 */`.

| ID    | Шаг Прил. А | Сценарий                                   | Ожидаемый результат           | Автотест                                  | Ручная проверка |
|-------|-------------|--------------------------------------------|-------------------------------|-------------------------------------------|-----------------|
| TC-01 | 1–2         | Онбординг → «Создать героя» → «Готово»     | Открыт главный экран          | `app/.../e2e/DemoScenarioTest` (e2e)      | —               |
| TC-02 | 3           | Главный → «Магазин»                        | Открыт магазин                | `features/home/ui/.../HomeScreenTest` (comp) | —               |
